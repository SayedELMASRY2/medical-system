# Git Commit Workflow Rule

## Automated Commit Policy
- **Target Branch**: All commits MUST be made on the `syd` branch.
- **Commit After Modifications**: After completing meaningful modifications or file edits in the project, automatically stage and create a descriptive git commit on `syd`.
- **Do Not Push Automatically**: Never execute `git push` unless the user explicitly requests to push to the remote repository.
- **Commit Messages**: Write clear, imperative commit messages describing the changes made (e.g., `feat(rag): add hybrid retriever and openrouter configuration`).
