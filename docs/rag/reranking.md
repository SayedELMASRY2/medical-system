# Reranking Strategy

## Overview
After the hybrid retrieval step, the system applies a Cross-Encoder Reranker. This model evaluates the semantic relationship between the query and the retrieved chunks simultaneously, providing a much more accurate relevance score than cosine similarity alone.

## Reranking Process
- **Input**: The top-40 fused results generated by the RRF step in the hybrid retrieval phase.
- **Model**: Cohere Rerank API (cross-encoder architecture).
- **Execution**: The system pairs the query with each document chunk and scores the exact textual relevance.
- **Output**: The reranked list is truncated to the top-5 most relevant results for context window injection.

## Fallback Mechanism
If the Cohere Rerank API is unavailable or times out, the system automatically falls back to using the RRF scores directly from the retrieval phase. This ensures high availability of the RAG pipeline.

## Configuration
- `model`: `rerank-english-v3.0` (or appropriate medical equivalent)
- `top_n`: 5
- `relevance_threshold`: 0.70 (Chunks scoring below this after reranking are discarded entirely)

## Pydantic Models

```python
from pydantic import BaseModel
from typing import List

class RerankInput(BaseModel):
    query: str
    documents: List[str]
    top_n: int = 5

class RerankedResult(BaseModel):
    chunk_id: str
    relevance_score: float
    content: str
    metadata: dict
```
