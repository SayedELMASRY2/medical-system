# Agent Guidelines & Workflow Rules

## Git Workflow Rule
- **Automatic Commits**: After every modification, feature addition, or file update in the project, automatically create a clean git commit.
- **Push Restriction**: DO NOT run `git push` under any circumstances unless explicitly requested by the user.
- **Commit Formatting**: Follow conventional commit style (`feat:`, `fix:`, `docs:`, `chore:`, `refactor:`).
